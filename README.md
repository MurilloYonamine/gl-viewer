## GL Viewer

A 3D model viewer built with C++ and OpenGL, developed as a learning project to explore computer graphics, modern C++, and rendering techniques.

### Built With

- C++20
- OpenGL 4.6
- CMake
- GLFW & GLEW
- GLM
- Assimp
- Dear ImGui
